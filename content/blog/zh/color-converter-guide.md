前端开发中，颜色有三种最常见的表示方式：`#FF5733`、`rgb(255, 87, 51)`、`hsl(11, 100%, 60%)`。设计稿给 HEX，代码里要 HSL，颜色格式互转是每天的必修课。这篇文章讲清三种模型的原理和换算，并介绍一款 [颜色转换工具](/tools/color-converter) 帮你即转即用。

## 三种颜色模型

- **HEX（十六进制）**：`#RRGGBB`，每两位十六进制数表示一个通道，最常用于 CSS 和设计稿
- **RGB**：`rgb(红, 绿, 蓝)`，每个通道取值 0-255，是屏幕显示的基础模型
- **HSL**：`hsl(色相, 饱和度, 亮度)`，色相 0-360 度，更接近人对颜色的直觉

## HEX 与 RGB 的换算

换算非常简单，把两位十六进制转成十进制即可：

```js
// #FF5733
const hex = "#FF5733";
const r = parseInt("FF", 16); // 255
const g = parseInt("57", 16); // 87
const b = parseInt("33", 16); // 51
// rgb(255, 87, 51)
```

反向换算则把十进制转成十六进制并补零。

## 为什么 HSL 更适合调色

想调出「更亮的红色」，RGB 里要同时改三个值，而 HSL 里只需要提高亮度（L）：

```css
/* 更亮的红色 */
hsl(11, 100%, 60%);  /* 原色 */
hsl(11, 100%, 70%);  /* 提亮 */
```

这也让 HSL 成为设计系统中「色调 + 深浅」体系的基础。

## 配色方案是怎么生成的

围绕主色调整色相角度即可生成协调的配色：

- **单色**：同色相，变化饱和度和亮度
- **类比色**：色相 ±30°，相邻色自然协调
- **互补色**：色相 +180°，对比最强烈
- **三角色**：色相间隔 120°，活泼均衡
