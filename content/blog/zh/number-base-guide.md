`255`、`0xFF`、`0b11111111` 是同一个数。理解进制是读懂底层代码的前提：位运算、内存地址、颜色值、权限掩码，处处都是十六进制和二进制。这篇文章讲清四种进制的原理和换算，并用 [进制转换工具](/tools/number-base) 帮你免手算。

## 四种进制的含义

- **二进制（BIN）**：逢二进一，只有 `0` 和 `1`，计算机的底层语言
- **八进制（OCT）**：逢八进一，`0-7`，Unix 文件权限的代表
- **十进制（DEC）**：逢十进一，`0-9`，人类日常使用
- **十六进制（HEX）**：逢十六进一，`0-9` 和 `A-F`，颜色、内存地址的常见写法

## 十进制转其他进制：短除法

把 `42` 转成二进制：

```
42 ÷ 2 = 21 余 0
21 ÷ 2 = 10 余 1
10 ÷ 2 = 5  余 0
 5 ÷ 2 = 2  余 1
 2 ÷ 2 = 1  余 0
 1 ÷ 2 = 0  余 1
```

从下往上读余数：`101010`，即 `42 = 0b101010`。

## 编程中的进制写法

```js
const a = 255;      // 十进制
const b = 0xFF;     // 十六进制，等于 255
const c = 0b11111111; // 二进制，等于 255
const d = 0o377;    // 八进制，等于 255

// 任意进制 → 十进制
parseInt("FF", 16);      // 255
// 十进制 → 任意进制
(255).toString(16);      // "ff"
```

JavaScript 用 `parseInt(str, radix)` 和 `Number.prototype.toString(radix)` 就能在任意进制间转换。

## 位运算为什么要用十六进制

一位十六进制正好对应 **4 位二进制**，转换无需计算：

```
0xF → 1111
0x3C → 0011 1100
```

所以权限掩码、颜色值、协议字段都习惯用十六进制表示，简洁且与二进制一一对应。
