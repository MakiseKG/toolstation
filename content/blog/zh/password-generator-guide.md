每次注册都纠结密码怎么设？记忆负担和安全性总是打架。很多人以为「加个 @ 和 !」就安全了，但**密码学界的共识是：长度比复杂更重要**。这篇文章讲透密码强度原理，并用 [密码生成器](/tools/password-generator) 帮你一键生成安全密码。

## 为什么长度比复杂更重要

密码强度取决于**可能的组合总数**，也就是「字符集大小」的「长度」次方：

```
字符集^长度 = 组合数
26^10 ≈ 1.4×10^14   （10 位小写字母）
36^8  ≈ 2.8×10^12   （8 位小写+数字）
```

**长度每加 1 位，组合数翻字符集大小倍**；加符号只增加一点点基数。这就是为什么 `correct-horse-battery` 这类长密码，比 `P@ssw0rd!` 更难被暴力破解，却更好记。

## 什么才算强密码

- **足够长**：至少 12 位，重要账号 16 位以上
- **避免字典词**：`password`、`123456` 这类在破解字典里排名靠前
- **每个站点独立**：一个密码被泄露，不能连坐其他账号

## 生成器的核心：加密安全随机

普通 `Math.random()` 是伪随机，可被预测。生成密码必须用**加密安全随机数**：

```js
// 不安全的伪随机
Math.random().toString(36).slice(2);

// 加密安全随机
crypto.getRandomValues(new Uint32Array(10));
```

好的密码生成器会基于 `crypto.getRandomValues` 从字符集中均匀采样，保证每一位都不可预测。

- **两步验证优先**：重要账号开启 TOTP / 短信二次验证

- **长度 > 复杂**：加长是提升强度最有效的杠杆
